## Issues found and fixed during this test

1. **`--followup-only` clobbered the main analysis JSON.** Running Appendix A's
   commands in the documented order left
   `experiments/design_axes_analysis.json` holding only the follow-up results,
   because both modes defaulted to the same `--json-out` path. The follow-up
   mode now defaults to `experiments/design_axes_followup_analysis.json`, and
   Appendix A names both outputs.
2. **Figure PDFs were not byte-deterministic.** `savefig` stamped a creation
   date into each PDF, so a reproduction could not be checked with
   `git status`. The PDF writer now passes `metadata={"CreationDate": None}`.
3. **No dependency manifest.** The analysis needs `numpy`, `pandas`, `scipy`
   and `matplotlib`, which a reviewer had no way to discover. Added
   `requirements.txt` and a step 0 in the README's quick start.

## Not covered by this test

deliberately did not do. The reproduction verified is the one the paper claims
in Appendix A — that every table, figure and quoted statistic regenerates from
